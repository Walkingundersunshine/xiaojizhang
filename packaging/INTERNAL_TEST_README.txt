晓记账 0.1.0 - Windows x64 内部测试包

用途
====
此包仅用于本人或可信测试者进行内部测试，尚未进行代码签名，不是公开正式版。

运行方法
========
1. 将整个 ZIP 解压到同一个文件夹。
2. 不要只复制 xiaojizhang.exe；data 目录和 DLL 文件也是运行所必需的。
3. 双击 xiaojizhang.exe 启动。
4. Windows 可能因为程序未签名而显示安全提示；仅在确认文件来自本项目时运行。

数据说明
========
- 账本默认保存在当前 Windows 用户的应用数据目录，不在程序解压目录内。
- 更换电脑或删除本地数据前，请在“设置 > 数据管理”中创建 .jizhang 完整备份。
- CSV 只用于查看和程序处理，不能用于恢复。
- 遇到错误时，可在“设置 > 数据管理”中选择“导出诊断日志”；日志只在用户主动保存后离开 App 私有目录。

当前限制
========
- 这是 Windows x64 内部测试版，没有安装、卸载和自动更新程序。
- macOS 版本必须在 Mac 上单独编译和验证。
- 程序没有代码签名，不应直接用于公开下载分发。
