# 晓记账：二维码与备用短码有效期方案

| 项目 | 内容 |
| --- | --- |
| 技术决策编号 | T-049 |
| 日期 | 2026-07-30 |
| 当前状态 | 已选择并实现方案 1：2 分钟 |
| 前置决定 | 电脑显示短时二维码，Android 扫描；手动短码备用；配对信息只在局域网使用 |

## 要决定什么

电脑开始等待配对后，二维码及对应的备用手动短码可以使用多长时间。两者使用相同有效期，过期后必须由电脑重新生成。

## 方案 1：2 分钟

优势：二维码被他人看到后的可利用时间最短；适合手机和电脑通常同时在用户手边的个人配对场景。

劣势：打开手机、进入扫码页或处理相机权限较慢时可能过期，需要电脑重新生成。

成本和风险：无服务费用，开发成本与其他方案基本相同；需要在界面清楚显示倒计时和重新生成入口。

## 方案 2：5 分钟（原推荐）

优势：给首次授权相机和寻找手动输入入口留出较充分时间，安全性与操作时间较平衡。

劣势：二维码意外被看到后，可尝试连接的时间比 2 分钟更长。

成本和风险：无服务费用，开发成本与方案 1 基本相同。

## 方案 3：10 分钟

优势：操作最宽松，适合两台设备不在同一位置或需要较长时间输入地址和短码的情况。

劣势：一次性配对信息暴露后的有效窗口最长，不适合把电脑长期停留在配对页面。

成本和风险：无服务费用，开发成本与方案 1 基本相同，但安全风险相对最高。

## 已确定的实现规则

- 二维码和备用手动短码共用 2 分钟有效期，不分别延长。
- 签发时间和过期时间包含在二维码载荷中；Android 扫描时再次校验。
- 解析器拒绝有效期超过 2 分钟的载荷，也拒绝已经到期的载荷。
- 过期后一次性令牌立即失效，电脑必须生成新的令牌和二维码。
- 二维码或短码是否过期只影响本次首次配对，不会取消已经长期记住的设备。
- 一次性令牌、二维码内容和备用短码不得写入诊断日志。
