# 晓记账：桌面导航布局方案

| 项目 | 内容 |
| --- | --- |
| 产品决策编号 | P-007 |
| 日期 | 2026-07-29 |
| 当前状态 | 已选择并实现方案 1：左侧导航栏 |

## 1. 要决定什么

决定 Windows 和 macOS 主窗口如何在“花销记录、统计、分类管理、设置”之间切换。

## 2. 方案 1：左侧导航栏（推荐）

窗口左侧始终显示图标和名称，右侧显示当前页面；窗口较窄时可以收起为图标。

优势：符合桌面软件习惯，当前位置清楚，后续增加功能也容易扩展，宽屏利用率好。

劣势：会占用一小部分横向空间，小窗口需要自动收起。

## 3. 方案 2：顶部标签栏

在窗口顶部横向排列“记录、统计、分类、设置”。

优势：简单直观，首版页面少时很清爽。

劣势：功能增多后容易拥挤；分类管理等长页面的纵向空间会略少。

## 4. 方案 3：首页功能卡片

启动后展示大卡片入口，进入具体页面后使用返回按钮回首页。

优势：对新用户友好，视觉上容易做得醒目。

劣势：页面之间切换需要更多点击，用户不容易持续看到当前位置，不适合高频记账。

## 5. 我的建议

建议选择 **方案 1：左侧导航栏**。晓记账是高频桌面工具，左侧导航能快速切换记录、统计和分类管理，也更适合未来增加导出、备份等设置功能。Windows 和 macOS 可以共用同一结构，再分别调整窗口细节。
