## 2. 下载方案 1：继续 Google 官方源

来源：`storage.googleapis.com`

优势：

- Flutter 官方直接发布源，来源最直接。
- 可以在当前约 4.6 MB 断点处继续下载。

劣势：

- 当前网络实测速度极慢，可能需要数小时甚至更久。
- 下载中断概率较高。

## 3. 下载方案 2：中国镜像 + 官方校验

来源：Flutter 中文社区提供的 `storage.flutter-io.cn` 镜像。

做法：从中国镜像下载同版本压缩包，同时从 Flutter 官方发布信息取得 SHA-256 校验值；下载后计算本地文件哈希，只有与官方值完全一致才解压使用。

优势：

- 在中国网络环境下通常明显更快、更稳定。
- 使用官方 SHA-256 校验，可以发现文件损坏或内容被替换。
- 下载结果验证通过后，与官方发布文件保持一致。

劣势：

- 文件传输不是直接来自 Google 官方服务器，而是经过镜像。
- 需要增加哈希校验步骤。

## 4. 下载方案 3：GitHub stable 分支

来源：Flutter 官方 GitHub 仓库。

优势：

- 代码来源可查看，版本标签清楚。
- 可以通过 Git 切换版本。

劣势：

- GitHub 在当前网络环境下也可能较慢或不稳定。
- 克隆后仍要下载 Flutter 组件，步骤更多。
- 占用空间和初始化时间通常更大。

## 5. 我的建议

建议选择 **方案 2：中国镜像下载，并使用 Flutter 官方 SHA-256 严格校验**。

这样可以改善下载速度，同时不直接信任镜像内容。哈希不一致时会立即停止，不解压、不运行文件，并向用户报告。
