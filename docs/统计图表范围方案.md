## 1. 要决定什么

决定首版统计页面除金额汇总外，需要展示哪些可视化图表。

## 2. 方案 1：汇总卡片 + 分类横向条形图（推荐）

展示本位币折算总额、各原币金额、汇率状态，并用横向条形图比较一级分类支出。条形图使用 Flutter 基础组件绘制，不增加图表依赖。

优势：分类大小容易比较；文字和金额清楚；小分类仍可阅读；无第三方图表依赖；Windows/macOS 表现稳定。

劣势：暂不显示每日趋势和饼图；视觉效果相对克制。

成本：低到中。

## 3. 方案 2：汇总卡片 + 环形分类图

使用第三方图表库展示各一级分类占比，点击扇区查看金额。

优势：占比关系直观，视觉效果更丰富。

劣势：分类多时扇区和标签拥挤；颜色区分和无障碍体验更难；需要增加并长期维护图表依赖。

成本：中等。

## 4. 方案 3：分类图 + 每日趋势图

同时提供分类占比图和按日折线/柱状趋势，支持本月、上月和自定义日期范围。

优势：信息最丰富，可以同时看“花在哪里”和“什么时候花”。

劣势：首版开发和测试量最大；空数据、多币种、汇率失败、窗口缩放等状态更复杂；页面可能显得拥挤。

成本：高。

## 5. 我的建议

建议选择 **方案 1：汇总卡片 + 分类横向条形图**。它能回答首版最重要的问题，同时保持金额清楚、依赖少和跨平台稳定。数据库和统计服务会保留按日聚合能力，后续增加趋势图不需要修改原始账目结构。
