## 1. 要决定什么

决定用户点击“记一笔”后，金额、货币、两级分类、时间和备注表单在桌面窗口中如何显示。

## 2. 方案 1：右侧滑出面板（推荐）

表单从窗口右侧滑出，占用约 420～480 像素；左侧花销列表仍然可见。窗口过窄时自动改为整页。

优势：符合桌面高频工具习惯；录入时仍能参考最近账目；保存后立即看到列表变化；新增和编辑可以复用同一面板。

劣势：小窗口需要额外适配；面板宽度不适合放非常复杂的表单。

## 3. 方案 2：居中弹窗

点击后在窗口中央打开对话框，背景暂时不可操作。

优势：开发简单，用户注意力集中；Windows 和 macOS 表现容易保持一致。

劣势：日期、分类和备注同时出现时会比较拥挤；误关弹窗可能丢失未保存输入；连续记多笔时效率一般。

## 4. 方案 3：独立整页

点击后切换到完整的新增页面，保存或取消后返回列表。

优势：空间最充足，错误提示和将来扩展图片、账户等字段最容易；窄窗口也好适配。

劣势：录入时看不到花销列表；每次新增都发生整页切换，高频记账的连续感较弱。

## 5. 我的建议

建议选择 **方案 1：右侧滑出面板**。首版表单字段数量适中，面板能够兼顾快速录入和桌面空间利用。实现时会保留响应式规则，小窗口自动使用整页，避免内容拥挤。
